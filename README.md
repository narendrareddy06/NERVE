# NERVE

**Plan. Execute. Recover.**

NERVE is a personal life execution system designed to help manage projects, goals, tasks, focus sessions, rewards, and recovery.

## Status

🚧 Under active development

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- Supabase

## Planned Features

- Project & goal management
- Daily and weekly planning
- Manual focus timer
- XP and rewards
- Progress tracking
- Recovery planning
- Smart scheduling
- AI-assisted planning
